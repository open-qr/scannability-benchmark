Will this QR code scan?

The "you can cover 30% with a logo" rule is roughly 3× too optimistic. Drag the controls: this is the study's model, running live, no server. Watch it grade fragile as the logo crosses the worst-case ceiling, and see which decoders drop out.

The safe / risky / fragile grade is calibrated to the study's held-out worst-case decode rate (it is a verdict, not a decode probability). The per-decoder row shows which of the four benchmarked libraries read the design. "Any reader" is the weakest deployed tier (ZBar, OpenCV, and the scanners inside kiosks, POS terminals and apps); "Modern phones" is the stronger tier (zxing-cpp, WeChat) that current phone cameras behave like.

Model: the Scannability Margin, a separate model per decoder fit on 58,048 decode attempts (per-decoder held-out AUC 0.94 to 0.97). Open data + method in the preprint. Code: scannability_score.ts · CC-BY-4.0.
